# Simple Interest Calculator

## Description
This project is a simple interest calculator application. It is used to calculate interest based on principal amount, interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Use
1. Enter the principal amount (initial money)
2. Enter the interest rate (percentage)
3. Enter the time period (in years or months)
4. Click the calculate button
5. The result will show the total interest

## Example
Principal: 1,000,000  
Rate: 10%  
Time: 2 years  

Result: 200,000

## Features
- Simple and easy to use
- Fast calculation
- Supports basic interest calculation

## Purpose
This project is created for learning basic programming logic and financial calculation.
